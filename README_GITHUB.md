## 🚀 快速开始

### 前置条件
- Node.js ≥ 18
- npm 或 pnpm

### 安装

```bash
# 克隆仓库
git clone https://github.com/你的用户名/requirement-pool.git
cd requirement-pool

# 安装依赖
pnpm install
# 或使用 npm
npm install
```

### 运行

```bash
# 开发模式（热更新）
pnpm dev

# 生产编译
pnpm build

# 生产运行
pnpm start

# 启动脚本（macOS）
chmod +x ./启动需求池.command
./启动需求池.command
```

### 访问

打开浏览器访问：**http://localhost:3000**

## 📖 使用指南

### 基本操作

#### 1. 创建项目
1. 点击"+ 新建项目"
2. 填写项目信息
   - 项目名称（必填）
   - 项目代码（用于标识）
   - 描述（可选）
   - 优先级（P0-P3）
3. 配置环境系统（可选）
   - Jira、Linear、GitHub 等
4. 添加团队成员（可选）
5. 保存项目

#### 2. 创建需求
1. 选择目标项目
2. 点击"+ 新建需求"
3. 填写需求详情
   - 名称（必填）
   - 优先级
   - 版本
   - 业务描述
   - 验收标准
4. 分配责任人和标签
5. 提交

#### 3. 搜索和筛选
1. 在搜索框输入关键词
2. 使用筛选面板设置条件
3. 选择排序方式
4. 结果自动更新

#### 4. 批量操作
1. 选中多个需求（复选框）
2. 在选中栏中选择操作
3. 确认执行

#### 5. 不同视图
- **表格视图** - 适合数据分析
- **卡片视图** - 适合视觉浏览
- **看板视图** - 适合拖拽工作流

### 系统设置

#### 外观设置
- 主题选择（亮色/暗色/自动）
- 字体大小（小/正常/大）
- 界面密度（紧凑/舒适/宽松）
- 语言选择（中文/英文）

#### 高级设置
- 自动备份周期
- 调试模式
- 性能分析
- 数据库优化

#### 网络设置
- 监听地址配置
- 端口设置
- LAN 访问
- IP 白名单

#### Git 同步
- 仓库地址
- 分支设置
- 数据文件路径
- 提交模板
