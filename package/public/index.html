「业务需求描述」将承载标准化需求正文与业务规则；「验收标准」使用 - [ ] 清单；「影响范围」可包含待确认事项。导入记录来源标记为「AI-Jira标准化」。

网络配置

配置配套服务启动时的监听地址和网络访问范围。当前 HTML 本身仍是本地文件；设置会保存并可导出给启动器或服务端读取。

监听服务

选择「仅本机」时只建议使用 127.0.0.1；允许局域网访问时，应由实际服务配置防火墙、鉴权和 HTTPS。本页面不会自行开启端口。

项目设置

设置新建需求的项目级默认值。项目名称和代码仍在左侧项目编辑入口维护。

Git 协同与版本

保存 Git 仓库同步参数，并导出可提交仓库的需求池数据文件。本地 HTML 不会直接执行 Git 命令，也不会在浏览器中保存访问令牌。

安全提示：Git 用户名、密码和访问令牌请放在系统凭据管理器或 Git Credential Manager 中，不写入需求池配置。
